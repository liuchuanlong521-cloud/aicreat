##  一、AIGC 行业概述：一场内容生产力的革命

###  1.1 什么是 AIGC？

AIGC（Artificial Intelligence Generated Content）是指利用人工智能技术自动生成内容的新型生产方式。与传统的 PGC（专业生成内容）和 UGC（用户生成内容）相比，AIGC 的核心特征是：

<table><thead><tr><th>维度</th><th>PGC（专业生成）</th><th>UGC（用户生成）</th><th>AIGC（AI 生成）</th></tr></thead><tbody><tr><td><strong>生产主体</strong></td><td>专业团队/创作者</td><td>普通用户</td><td>AI 模型 + 人机协作</td></tr><tr><td><strong>生产效率</strong></td><td>低（按天/周计）</td><td>中（按小时计）</td><td>极高（按秒计）</td></tr><tr><td><strong>内容成本</strong></td><td>高</td><td>低</td><td>极低</td></tr><tr><td><strong>质量稳定性</strong></td><td>高</td><td>参差不齐</td><td>可控且持续提升</td></tr><tr><td><strong>个性化能力</strong></td><td>弱</td><td>中</td><td>强</td></tr><tr><td><strong>规模化能力</strong></td><td>弱</td><td>中</td><td>极强</td></tr></tbody></table>

::: tip 核心考点
AIGC 的本质

AIGC 的本质不是"替代人类创作"，而是**将内容生产的边际成本趋近于零**，让每个人都拥有"超级创作助手"。
:::

##  三、赛道一：文本生成（Text Generation）

###  3.1 行业概述

文本生成是 AIGC 最成熟、商业化程度最高的赛道。以 GPT 系列为代表的大语言模型（LLM）已经能够胜任写作、翻译、摘要、问答、编程辅助等多种任务。

::: warning 名师旁白
产品经理需要关注的文本生成指标

-   **上下文长度**：决定模型能处理多长的输入（Kimi 支持 200 万字上下文是核心卖点）
-   **推理能力**：数学、逻辑、代码等需要深度思考的任务表现
-   **幻觉率**：模型编造虚假信息的概率，直接决定产品可用性
-   **延迟**：首 token 响应时间和整体生成速度
-   **多语言能力**：中文理解生成是否达到可用水平
:::

Stable Diffusion 对产品经理的启示

**开源 vs 闭源的选择**：

-   Midjourney 选择闭源，走精品路线，靠美学壁垒收费
-   Stable Diffusion 选择开源，走生态路线，靠服务和授权收费

两种模式都成功，关键在于**战略一致性**。如果做开源，就要彻底拥抱社区；如果做闭源，就要在体验上做到 10 倍好。

###  5.1 行业概述

::: danger 视频生成为什么比图像生成难 100 倍？
视频生成为什么比图像生成难 100 倍？

1.  **时序一致性**：人物在每一帧都要保持一致，不能"变脸"
2.  **物理规律**：物体运动要符合真实世界的物理定律
3.  **计算量**：视频 = 连续图像 × 帧率，计算量指数级增长
4.  **数据稀缺**：高质量视频-文本配对数据远少于图像数据
:::

###  8.1 Prompt 工程的产品化

::: danger 产品设计的反模式：让用户写 Prompt
产品设计的反模式：让用户写 Prompt

**正确做法**：把 Prompt 工程封装成产品功能，让用户通过界面操作即可。

###  8.2 多模态交互设计

```
多模态交互设计原则
─────────────────────────────────────────────────

输入侧：
  文本 → 最通用，但表达有限
  语音 → 最自然，适合移动端
  图像 → 一图胜千言，适合视觉描述
  文件 → 深度处理，适合文档分析
  
输出侧：
  文本 → 信息密度高，适合深度内容
  图像 → 直观生动，适合创意表达
  视频 → 沉浸感强，适合动态展示
  音频 → 伴随式消费，适合场景化

设计原则：
  1. 让用户选择最自然的输入方式
  2. 让 AI 选择最合适的输出方式
  3. 支持跨模态转换（文生图、图生文、文生视频）
  4. 保持输出的一致性和可控性
─────────────────────────────────────────────────
```

3.  **生态绑定化**：与百度搜索、百度网盘、百度文库深度整合

这种模式的优点是**技术复用率高**，缺点是**每个应用的体验深度可能不如独立产品**。
:::

###  10.2 三大核心挑战

::: danger 挑战一：算力成本与商业化的矛盾
挑战一：算力成本与商业化的矛盾

AIGC 的推理成本仍然很高：

-   GPT-4 级别的模型，一次对话成本约 $0.01-0.1
-   视频生成成本更高，Sora 级别的视频生成一次可能 $1-10
-   如果用户量大但付费率低，算力成本会拖垮公司

**解决方案方向**：

1.  模型压缩和蒸馏（用 GPT-4 教小模型）
2.  专用 AI 芯片（降低推理成本 10-100 倍）
3.  动态路由（简单问题用小模型）
:::
::: warning 名师旁白
挑战二：内容质量与可控性

AIGC 面临"好内容难生成，坏内容易传播"的困境：

-   高质量内容的生成仍需要专业 Prompt 和反复调优
-   低质量、错误信息、有害内容的生成门槛极低
-   用户对 AI 生成内容的信任度仍然不高

**解决方案方向**：

1.  强化学习人类反馈（RLHF）持续优化
2.  内容溯源和水印技术
3.  人机协作审核机制
:::
::: tip 核心考点
挑战三：版权与伦理困境

AIGC 的法律和伦理问题远未解决：

-   训练数据是否侵权？（《纽约时报》诉 OpenAI 等）
-   AI 生成内容的版权归属？
-   AI 替代人类工作的社会影响？
-   深度伪造技术的滥用风险？

**产品经理的应对**：

1.  在产品中明确标注 AI 生成内容
2.  建立内容审核和过滤机制
3.  提供用户控制权和选择权
4.  持续关注法规变化，合规先行
:::

作为 AI 产品经理，面对 AIGC 这个快速变化的领域，我想分享三个核心认知：
