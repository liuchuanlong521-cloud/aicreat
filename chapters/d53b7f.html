核心考点

前言

通过《产品经理与AI产品经理》的了解，你知道了产品经理和AI产品经理的区别，且仍想要去尝试学习、入门。那么，这一章节通过为你介绍实用性的书籍、网站、工具、专业术语，让你对AI产品经理有更进一步的理解。

特别提醒：AI产品经理首先得是一个好的产品经理，所以传统产品经理的基础能力（需求分析、产品设计、项目管理等）你必须掌握。在此基础上，再叠加AI领域的专业能力。

# 1、入门AI产品经理，推荐看这8本书

看书是为了让你更具体的了解产品经理的日常工作流，所要具备的专业技能，让你对AI产品经理这个岗位，有更体系化的认知。

# 传统产品经理基础（必读）

核心考点

阅读建议

先看这4本建立产品基础，再看AI相关书籍。

# 1）《人人都是产品经理》

入门产品经理的必读物，是原阿里产品苏杰大大的书，介绍了产品经理的工作流程，所需的基本知识和技能。看完以后，你会对产品工作有个基本的认知。

# 2）《启示录：打造用户喜爱的产品》

由Marty Cagan撰写的一本产品管理经典书籍，主要围绕人员、流程、产品三个角度展开，旨在帮助产品经理和团队从多个维度出发，打造出真正受用户喜爱的产品。

# 3）《用户体验要素》

由Jesse James Garrett撰写，详细介绍了用户体验的五个要素：战略层、范围层、结构层、框架层和表现层。强调设计产品时要"以用户为中心"。

# 4）《决胜B端：产品经理升级之路》

由B端产品专家杨堃所作，涵盖了B端业务调研、方案设计、需求迭代管理、企业级应用架构设计等。

# AI产品经理专项（必看）

核心考点

阅读建议

看完基础书籍后，再看这4本建立AI产品认知。

# 5）《AI产品经理：方法、实战与进阶》

专为AI产品经理编写的实战指南，系统讲解了AI产品的设计方法、模型评估指标、人机交互设计等内容。适合有一定产品基础后阅读。

# 6）《机器学习实战》

不需要你学会写代码，但需要理解机器学习的基本原理和常见算法（如分类、聚类、回归）。这本书用Python示例讲解，通俗易懂，帮助你建立对AI技术的直觉认知。

# 7）《深度学习入门：基于Python的理论与实现》

深度学习是AI的核心技术之一。这本书从零开始讲解神经网络原理，无需复杂数学基础。作为AI产品经理，你需要理解深度学习能做什么、不能做什么。

# 8）《生成式人工智能：人工智能的未来》

系统介绍AIGC（AI生成内容）、大语言模型（LLM）等前沿技术的原理和应用场景。帮助你理解ChatGPT、Midjourney等产品背后的技术逻辑。

# 1）人人都是产品经理

# 3）Papers With Code

将学术论文与开源代码对应起来的平台。AI产品经理需要了解最新的技术进展，这个网站可以帮你快速找到某篇论文的实现代码和效果数据。

# 4）Hugging Face

全球最大的AI模型开源社区。你可以在这里体验各种预训练模型，了解不同模型的能力和适用场景。作为AI产品经理，你需要知道"市场上有什么模型可用"。

# 5）ModelScope（魔搭社区）

阿里巴巴推出的AI模型开源社区，中文友好。可以在线体验各种中文大模型、多模态模型，了解国内AI技术生态。

# 6）机器之心

国内领先的AI媒体和产业服务平台，报道AI领域最新技术进展、产品动态和行业应用。适合每天浏览了解AI行业趋势。

# 7）InfoQ AI前线

聚焦AI工程实践和产品落地，有很多AI产品案例分享和技术实践经验。适合想了解"AI怎么落地到产品中"的产品经理。

# 8）Prompt Engineering Guide

Prompt Engineering（提示词工程）是AI产品经理的核心技能之一。这个网站系统讲解了如何与大模型高效交互，是AI产品经理必学的基本功。

# 4、AI产品经理一定要懂的AI专业术语

这些术语是AI产品经理日常工作中高频使用的，在面试时也会被问到。

# 机器学习基础类

术语解释
机器学习让计算机从数据中自动学习规律，而不是通过显式编程完成任务。分为监督学习、无监督学习、强化学习。
深度学习机器学习的一个分支，使用多层神经网络模拟人脑的工作方式，擅长处理图像、语音、文本等复杂数据。
神经网络模仿生物神经系统的计算模型，由大量相互连接的节点（神经元）组成，是深度学习的核心。
训练/推理训练：用数据教模型学习规律；推理：用训练好的模型对新数据做出预测。
过拟合/欠拟合过拟合：模型在训练数据上表现很好，但在新数据上表现差；欠拟合：模型太简单，无法捕捉数据规律。
特征工程从原始数据中提取、转换有用的信息（特征），供模型学习使用。好的特征直接影响模型效果。

# 大模型与AIGC类

术语解释
大语言模型（LLM）基于海量文本数据训练的超大规模神经网络模型，如GPT-4、Claude、文心一言等，能理解和生成自然语言。
AIGCAI Generated Content，人工智能生成内容。包括AI生成文本、图像、音频、视频、代码等。
Prompt给AI模型的输入指令或问题。Prompt的质量直接决定AI输出的质量。
Prompt Engineering提示词工程，通过优化Prompt的设计，让AI模型输出更准确、更符合预期的结果。
RAGRetrieval-Augmented Generation，检索增强生成。让大模型在回答时先检索外部知识库，再生成答案，减少"幻觉"。
幻觉（Hallucination）大模型生成看似合理但实际错误的内容。AI产品经理必须设计机制来降低幻觉对用户的负面影响。
Token大模型处理文本的最小单位，可以是一个字、一个词或一个子词。Token数量直接影响成本和模型处理能力。
上下文窗口大模型一次能处理的输入文本的最大长度。如GPT-4支持128K Token，Kimi支持200万字。

# 模型评估类

术语解释
准确率（Accuracy）模型预测正确的比例。适合类别均衡的场景。
精确率（Precision）模型预测为正例中，真正为正例的比例。高精确率意味着"宁可漏掉，不可错杀"。
召回率（Recall）所有真正例中，被模型正确找出的比例。高召回率意味着"宁可错杀，不可漏掉"。
F1值精确率和召回率的调和平均数，综合衡量模型效果。
A/B测试通过将用户随机分为两组，分别展示不同的产品版本，比较效果确定最优方案。
Baseline基准模型或基准效果，用于衡量新方案是否有提升。

# AI产品落地类

术语解释
模型即服务（MaaS）Model as a Service，将AI模型封装成API服务，供开发者调用。如OpenAI API、百度千帆等。
Fine-tuning微调，在预训练大模型的基础上，用特定领域的数据进一步训练，让模型更适合特定任务。
Embedding嵌入，将文本、图像等数据转换为数值向量的技术。常用于语义搜索、知识库检索等场景。
Agent智能体，能自主规划、使用工具、完成复杂任务的AI系统。如AutoGPT、各类AI助手。
多模态能同时处理和理解多种数据类型（文本、图像、音频、视频）的AI模型。如GPT-4V、Gemini。

# 5、AI产品经理的学习路径建议

核心考点

给0基础同学的建议

如果你完全没有产品经验，建议按以下路径学习：

第一阶段：建立产品基础（1-2个月）

  • 阅读《人人都是产品经理》《启示录》
  • 学习Axure或Figma，画出你的第一个产品原型
  • 尝试拆解一个你常用的APP，写一份竞品分析报告

第二阶段：了解AI技术（1-2个月）

  • 阅读《AI产品经理：方法、实战与进阶》《机器学习实战》
  • 每天使用ChatGPT/Claude/文心一言，体验大模型的能力边界
  • 在Hugging Face或ModelScope上体验不同的AI模型
  • 学习Prompt Engineering，掌握与大模型高效对话的技巧

第三阶段：动手实践（持续）

  • 用Coze或Dify搭建一个简单的AI Bot
  • 找一个生活中的痛点，思考"AI能不能解决这个问题"
  • 尝试写一份AI产品需求文档（PRD）

第四阶段：求职准备

  • 准备1-2个AI产品相关的项目经验（可以是课程作业、个人项目）
  • 关注AI产品经理的招聘信息，了解市场需求
  • 刷AI产品经理面试题，重点准备"AI技术理解"和"产品设计"两方面

# 6、传统产品经理基础术语速查

以下术语是传统产品经理必须掌握的基础知识。因为AI产品经理首先是产品经理，所以这些术语同样需要掌握。

# 产品文档类

术语解释
BRD商业需求文档，描述产品的商业价值、市场机会和盈利模式。
MRD市场需求文档，基于BRD，细化目标市场、用户需求、竞品分析等。
PRD产品需求文档，详细描述产品功能、特性和要求，为研发团队提供清晰指引。
用户画像基于市场调研和用户数据创建的虚拟用户模型，帮助了解目标用户的需求和行为。
MVP最小可行产品，通过开发最少量的功能验证市场需求和用户反馈。
商业模式企业为实现盈利和增长所选择的商业策略和运营方式。

# 技术协作类

术语解释
API/接口应用程序接口，用于客户端与服务器之间的数据传输。
SDK软件开发工具包，辅助开发某一类软件的文档、范例和工具的集合。
JSON轻量级的数据交换格式，方便阅读和编写，易于机器解析。
数据库用于存储和管理数据的系统。
同步/异步同步：任务按顺序执行；异步：不阻塞主线程，允许其他任务继续执行。
开发/测试/生产环境分别用于代码开发、功能测试、正式提供服务的三套环境。

# 数据分析类

术语解释
PV页面浏览量，用户每次访问页面均记录一次。
UV独立访问量，页面被多少人看过，同一用户多次访问只计一次。
DAU/MAU日/月活跃用户数量，反映产品的用户活跃情况。
留存率新增用户中后续持续使用产品的比例。
转化率实现某一目标的用户数与访问用户数的比例。
埋点在产品中设置数据采集点，用于收集用户行为数据。
AARRR模型用户增长模型：获取→激活→留存→收益→推荐。

# 7、写在最后

AI产品经理是一个充满机遇的岗位，但也对综合能力提出了更高要求。

你需要同时做到：

  • 像传统产品经理一样，深刻理解用户需求、设计优秀的产品体验
  • 像AI从业者一样，理解技术边界、能与算法团队高效协作、能判断AI方案的可行性

建议养成以下习惯：

  • 每天花30分钟浏览AI行业动态（机器之心、InfoQ等）
  • 每周深度体验1-2个AI产品，思考它的产品设计亮点和可改进之处
  • 每月动手实践一个AI小项目（哪怕只是用Coze搭一个Bot）

AI产品的迭代速度远超传统互联网产品，保持好奇心和持续学习的态度，是你在这个领域立足的根本。
