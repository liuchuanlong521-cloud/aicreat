核心考点

前言

嗨，欢迎来到 AIGC（AI Generated Content，人工智能生成内容）的行业深度拆解章节。

如果你是一位正在学习 AI 产品的同学，或者正在思考"AI 到底怎么落地到商业场景"的产品经理，那么这一章就是为你量身打造的。

AIGC 不是昙花一现的风口，而是一场正在重塑内容生产方式的底层革命。从 2022 年 ChatGPT 的爆火，到 2024 年 Sora 的惊艳亮相，再到 2025 年多模态大模型的全面开花——AIGC 正在以惊人的速度渗透进文本、图像、视频、音频、代码等每一个内容生产领域。

本章将从 AI 产品经理的视角，带你系统拆解 AIGC 的行业版图、头部产品、商业模式、设计方法论以及未来趋势。读完这一章，你将拥有一张完整的 AIGC 行业认知地图。

# 一、AIGC 行业概述：一场内容生产力的革命

# 1.1 什么是 AIGC？

AIGC（Artificial Intelligence Generated Content）是指利用人工智能技术自动生成内容的新型生产方式。与传统的 PGC（专业生成内容）和 UGC（用户生成内容）相比，AIGC 的核心特征是：

维度PGC（专业生成）UGC（用户生成）AIGC（AI 生成）
生产主体专业团队/创作者普通用户AI 模型 + 人机协作
生产效率低（按天/周计）中（按小时计）极高（按秒计）
内容成本高低极低
质量稳定性高参差不齐可控且持续提升
个性化能力弱中强
规模化能力弱中极强

核心考点

AIGC 的本质

AIGC 的本质不是"替代人类创作"，而是将内容生产的边际成本趋近于零，让每个人都拥有"超级创作助手"。

# 驱动力三：商业化场景全面打开

核心考点

为什么 2023 年是 AIGC 商业化元年？

因为这一年同时满足了三个条件：

  1. 模型能力跨越可用性阈值（GPT-4 达到人类水平）

  3. 用户习惯被 ChatGPT 教育完成（2 个月破 1 亿用户，史上最快）

# 三、赛道一：文本生成（Text Generation）

# 3.1 行业概述

文本生成是 AIGC 最成熟、商业化程度最高的赛道。以 GPT 系列为代表的大语言模型（LLM）已经能够胜任写作、翻译、摘要、问答、编程辅助等多种任务。

名师旁白

产品经理需要关注的文本生成指标

  • 上下文长度：决定模型能处理多长的输入（Kimi 支持 200 万字上下文是核心卖点）
  • 推理能力：数学、逻辑、代码等需要深度思考的任务表现
  • 幻觉率：模型编造虚假信息的概率，直接决定产品可用性
  • 延迟：首 token 响应时间和整体生成速度
  • 多语言能力：中文理解生成是否达到可用水平

# 四、赛道二：图像生成（Image Generation）

# 4.1 行业概述

图像生成是 AIGC 商业化第二成熟的赛道。从 2022 年 Stable Diffusion 开源开始，AI 绘画迅速从"玩具"变成"生产力工具"，广泛应用于设计、电商、营销、游戏、影视等领域。

# 4.2 头部产品拆解

# 🏆 Midjourney

维度详情
产品定位最美的 AI 绘画工具，面向创意专业人士
核心功能文生图、图生图、风格迁移、图片融合、区域重绘、无限扩图
技术路线自研 Diffusion 模型，闭源，专注美学质量
用户画像设计师、插画师、艺术家、营销从业者（Discord 社区 2000 万+）
商业模式纯订阅制：Basic $10/月 → Standard $30/月 → Pro $60/月
年收入约 5-7 亿美元（团队仅 40 人左右，人效极高）

核心考点

Midjourney 的产品设计哲学（AI PM 必学）

  1. Discord 先行策略：选择 Discord 作为载体，天然获得社交传播和社区反馈
  2. 极致美学追求：不追求功能最多，而是追求"出图效果最好"
  3. 极简交互设计：用 /imagine 一个命令降低使用门槛
  4. 社区驱动迭代：公开频道让用户互相学习 Prompt，形成 UGC 飞轮
  5. 渐进式收费：免费 25 张后付费，让用户先上瘾再转化

Stable Diffusion 对产品经理的启示

开源 vs 闭源的选择：

  • Midjourney 选择闭源，走精品路线，靠美学壁垒收费
  • Stable Diffusion 选择开源，走生态路线，靠服务和授权收费

两种模式都成功，关键在于战略一致性。如果做开源，就要彻底拥抱社区；如果做闭源，就要在体验上做到 10 倍好。

# 五、赛道三：视频生成（Video Generation）

# 5.1 行业概述

视频生成是 2024-2025 年 AIGC 最热门的赛道。Sora 的发布证明 AI 已经能够理解物理世界并生成连贯的视频内容，这被认为是通往世界模型（World Model）的重要一步。

视频生成为什么比图像生成难 100 倍？

视频生成为什么比图像生成难 100 倍？

  1. 时序一致性：人物在每一帧都要保持一致，不能"变脸"
  2. 物理规律：物体运动要符合真实世界的物理定律
  3. 计算量：视频 = 连续图像 × 帧率，计算量指数级增长
  4. 数据稀缺：高质量视频-文本配对数据远少于图像数据

# 5.2 头部产品拆解

维度详情

# 8.1 Prompt 工程的产品化

Prompt 工程是 AIGC 产品的核心交互方式，但普通用户不应该是 Prompt 工程师。

产品设计的反模式：让用户写 Prompt

产品设计的反模式：让用户写 Prompt

错误做法：给用户一个输入框，让他们自己琢磨怎么写 Prompt。

正确做法：把 Prompt 工程封装成产品功能，让用户通过界面操作即可。

Prompt 产品化的四个层次：

层次实现方式示例用户门槛
L1：模板化提供预设模板Midjourney 的 /describe，ChatGPT 的 GPTs低
L2：结构化表单式输入，后端拼接 Prompt图像生成工具的风格/光线/构图选项低
L3：对话式多轮对话引导，AI 帮用户完善需求DALL-E 3 在 ChatGPT 中的生图方式极低
L4：隐式化用户无感知，系统自动优化 Prompt智能助手根据场景自动选择最佳 Prompt无

# 8.3 版权与合规设计

名师旁白

AIGC 产品的合规雷区

  1. 训练数据版权：用受版权保护的内容训练模型是否合法？（全球诉讼不断）
  2. 生成内容版权：AI 生成的内容版权归谁？（美国版权局：纯 AI 生成不享版权）

合规设计 Checklist：

## AIGC 产品合规设计 Checklist

### 内容安全
- [ ] 输入过滤：检测并拦截有害 Prompt

- [ ] 事后追溯：生成内容水印/溯源标识

- [ ] 训练数据授权：确保数据来源合法

- [ ] 数据处理协议：承诺不将用户数据用于训练
- [ ] 企业隔离：企业版数据完全隔离
- [ ] 最小收集：只收集必要的用户数据
- [ ] 删除权利：用户可要求删除个人数据

# 案例一：Midjourney——40 人团队如何创造 7 亿美元年收入

# 产品背景

Midjourney 由 David Holz 于 2022 年创立，团队至今仅约 40 人，却实现了年化 5-7 亿美元的收入，是 AIGC 领域"小而美"的典范。

# 成功要素拆解

成功要素具体做法PM 启示
极致聚焦只做图像生成，不做视频/文本/其他资源有限时，单点突破比全面铺开更有效
美学优先所有技术决策以"出图更美"为标准ToC 产品的核心竞争力是感性体验，不是技术指标
社区驱动Discord 社区即产品，用户互相教学社区是最高效的获客和教育渠道
技术闭环自研模型，不依赖开源核心技术自主可控是长期竞争力的基础
极简定价三档订阅，无复杂积分计算定价简单透明，降低用户决策成本

核心考点

Midjourney 的 Prompt 设计智慧

Midjourney 的 Prompt 语法是一种渐进式学习设计：

  • 新手：直接输入自然语言描述，也能出好图
  • 进阶：学习 /imagine 后面的参数（--ar 16:9 调整比例）
  • 高级：使用 --s（风格化程度）、--c（ chaos 混乱度）精细控制
  • 专家：使用 :: 权重语法、多 Prompt 融合

这种设计让每个阶段的用户都能找到适合自己的使用方式。

# 10.2 三大核心挑战

挑战一：算力成本与商业化的矛盾

挑战一：算力成本与商业化的矛盾

AIGC 的推理成本仍然很高：

  • GPT-4 级别的模型，一次对话成本约 $0.01-0.1
  • 视频生成成本更高，Sora 级别的视频生成一次可能 $1-10
  • 如果用户量大但付费率低，算力成本会拖垮公司

解决方案方向：

  1. 模型压缩和蒸馏（用 GPT-4 教小模型）
  2. 专用 AI 芯片（降低推理成本 10-100 倍）
  3. 动态路由（简单问题用小模型）

名师旁白

挑战二：内容质量与可控性

AIGC 面临"好内容难生成，坏内容易传播"的困境：

  • 高质量内容的生成仍需要专业 Prompt 和反复调优
  • 低质量、错误信息、有害内容的生成门槛极低
  • 用户对 AI 生成内容的信任度仍然不高

解决方案方向：

  1. 强化学习人类反馈（RLHF）持续优化
  2. 内容溯源和水印技术
  3. 人机协作审核机制

核心考点

挑战三：版权与伦理困境

AIGC 的法律和伦理问题远未解决：

  • 训练数据是否侵权？（《纽约时报》诉 OpenAI 等）
  • AI 生成内容的版权归属？
  • AI 替代人类工作的社会影响？
  • 深度伪造技术的滥用风险？

产品经理的应对：

  1. 在产品中明确标注 AI 生成内容
  2. 建立内容审核和过滤机制
  3. 提供用户控制权和选择权
  4. 持续关注法规变化，合规先行

感谢你读到这里。这一章我们从行业概述到赛道拆解，从产品方法论到典型案例，系统梳理了 AIGC 的全貌。

作为 AI 产品经理，面对 AIGC 这个快速变化的领域，我想分享三个核心认知：

第一，技术能力只是起点，不是终点。 大模型技术在快速民主化，今天只有 OpenAI 能做到的事情，明天可能每个创业公司都能做到。真正的壁垒在于对场景的理解和产品化的能力。

第二，用户要的不是 AI，是更好的结果。 不要陷入"为了 AI 而 AI"的陷阱。用户不关心你用了什么模型，只关心能不能更快、更好、更便宜地达成目标。

第三，合规和安全是底线，不是可选项。 AIGC 的监管只会越来越严格，在产品设计之初就要把内容安全、版权合规、隐私保护作为核心要素考虑，而不是事后补丁。
