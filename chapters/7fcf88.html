核心考点

前言

俗话说得好，磨刀不误砍柴工。在正式踏入 AI 产品经理的学习旅程之前，先把工具箱整理到位，后面才能跑得顺畅。

这一节的目标很明确：帮你把「用得上」的工具和账号配齐，然后亲手跑通一次——打开 Claude Code，用自然语言描述需求，让它帮你搭一个小页面或实现一个小功能。只要经历完「说话 → 出代码 → 调通」这一整套流程，这一节就算过关。注册和配置的细节官网都有，这里不会手把手截图教，只告诉你「该准备什么、为什么准备、去哪里找」。卡住的时候，搜一下或者直接问 AI 都行，这也是 Vibe Coding 的一部分。

# 五、现在，立刻，做一次实践（这节最重要）

不管你选了哪个方案，看到这里请立刻停下来，打开 Claude Code，做一次。 不是看完就完事了，是真的动手。

# 你需要达到什么水平（面试时能用上的）

系统学完并动手练完之后，你应该能自信地讲出以下几点：

  • 能清晰描述需求 —— 用纯自然语言说清楚"我要一个什么样的页面/功能"，不需要会写代码
  • 能读懂并微调 AI 生成的代码 —— 改改文案、调调样式、修修简单逻辑，至少能指出"这里我想要的是 XX 效果"
  • 会借 AI 排错 —— 报错信息贴给 Claude Code，让 AI 帮你分析原因、给出修复方案，这也是 Vibe Coding 的核心能力
  • 能讲出自己的实践故事 —— 面试时不是背概念，而是说"我让 Claude Code 做了 XX，中间遇到 XX 报错，后来发现是 XX 原因，用 XX 方式解决的"。有真实故事可讲，比空口说"我会"强十倍

# 推荐你马上做的小任务（三选一）

打开 Claude Code，挑一个：

  1. 做一个带标题和几个按钮的极简网页
  2. 做一个本地运行的"聊天"界面样子（不用接真实 API，有界面就行）
  3. 做一个简单的检索 Demo（后面第 4 章讲 RAG 时会用到这个基础）

关键点：

  • 用自然语言描述需求，不要自己写代码
  • 大概率一次跑不通，没关系，调几次
  • 记下你卡住的地方和怎么解决的，这就是你的面试素材

书中不会给"复制粘贴就能跑"的固定步骤，因为 Claude Code 和依赖库更新太快，截图和命令很快就会过时。你亲手踩坑、亲手调通的经历，才是面试时最值钱的东西。

# 进阶小实验：感受 AI 的"不确定性"

如果你已经用 Claude Code 成功生成过一次，再做一件事：用完全相同的一段话描述需求，连续让 AI 生成 2～3 次，对比结果。

你会发现：

  • 每次出来的东西都不一样
  • 有时结构清晰，有时逻辑混乱
  • 同样的输入，输出并不确定

这不是 bug，这是 AI 的本质——概率生成。作为 AI 产品经理，你的日常工作就是：

  • 写出更精准的 Prompt，让输出更稳定可控
  • 设计兜底和容错机制，让 AI 出错时产品不崩、用户不骂

做完这个实验，你对"AI 的能力边界在哪里"就有了真实的体感，比看十篇文章都管用。

# 六、你可能想问的

Q1：没有梯子，ChatGPT 用不了怎么办？

完全不影响。Kimi、DeepSeek、通义千问、文心一言，国内工具足够你学完整套内容。很多人没用过 ChatGPT 照样拿到了 AI PM offer。

Q2：学生党 / 手头紧，怎么省着花？

优先方案 A（Kimi + Claude Code 免费体验）。如果要用 DeepSeek API，它家的免费额度通常够用一段时间。

Q3：DeepSeek API 怎么接到 Claude Code 里用？

Claude Code 默认走 Anthropic 的 Claude 模型，但支持配置第三方 API（OpenAI 兼容格式）。具体操作搜「Claude Code 自定义模型配置」或直接问 Claude Code 自己。

# 七、自查清单：这节过关的标准

进入第 2 章之前，对照下面几项打勾：

  • [ ] 至少有一个活跃的 AI 对话账号（Kimi / DeepSeek / ChatGPT 都行）
  • [ ] Claude Code（或其他 AI 编程工具）已经装好了——这是硬门槛
  • [ ] 用 Claude Code 独立完成了一次小任务（搭页面、做界面、写脚本都行）——这是核心
  • [ ] 亲身体验过"说人话就能让 AI 写代码"的感觉
  • [ ] 可选：注册了 v0.dev（UI 生成）
  • [ ] 所有账号密码和 API Key 都妥善保存了

如果只有第 1 项打勾，后面几项都没做，建议先回头补上。现在的 AI PM 面试里，能讲清楚"我用 Claude Code 做过什么、怎么做的"的候选人，和只会说"我会用 ChatGPT 聊天"的候选人，竞争力完全不在一个层级。

本节只是 Vibe Coding 的"开胃菜"，目的是让你跑通第一次。Vibe Coding 作为 AI PM 的核心工作方式——包括它的演进历史、六步法工作流、L1-L3 分层放权机制、风险底线 SOP、四阶段升级路径——会在 4.7 / 4.8 做系统讲解。

# 八、不同阶段，该用什么工具

前面列的是"全家桶"，但你不需要一次性全装。下面按学习进度给出"最低配置 + 可选升级"，避免你一开始就被工具淹没。

# 按四周一个阶段推荐

阶段最低配置可选升级预计投入
第 1 周：找找感觉Kimi 网页版 + Claude Code 免费体验—¥0
第 2-4 周：跑 Demo+ DeepSeek API（充 ¥10）+ v0.dev+ Claude.ai 免费版¥10–50
第 5-8 周：做完整项目+ Claude Pro+ Vercel 免费版 + Supabase 免费层¥150–300
第 9 周以后：求职/实战+ Vercel 付费 + Agent 平台（Coze / Dify）+ GitHub Copilot¥300–500

# 避坑提醒

  • 第 1 周最大的坑：一上来就冲 ChatGPT Plus + Claude Pro + 各种付费工具全家桶——结果 90% 的功能你暂时用不上，纯烧钱
  • 第 5 周必须升级：免费版的速率和额度限制，做完整项目时根本扛不住，该花钱时要花

# 哪些工具已经过时了

  • ❌ Sora — OpenAI 已关停，详见 3.4 章
  • ❌ 早期国产对话产品 — 文心一言早期版、通义千问 1.x 等，都已被自家的新一代模型全面替代
  • ❌ Replit Agent — 已并入其他产品形态
  • ⚠️ GitHub Copilot — 还能用，但 Claude Code / Cursor 的综合能力已经全面超越，新人没必要再从 Copilot 入门

记住：工具年年换，能力带得走。 别在"装软件"上耗太多时间，多花时间在"用软件做出一个能讲的项目"上。

# 本章小结

走到这里，你应该已经：

  • ✅ 配齐了 AI 工具（至少一个对话模型 + Claude Code）

  • ✅ 切身感受到"不会写代码也能用 AI 开发"的爽感
  • ✅ 对 AI PM 的核心竞争力有了模糊但真实的认知
  • ✅ 知道卡住的时候该搜教程还是该问 AI
