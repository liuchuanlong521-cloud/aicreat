# 0、一名做过程序员的产品经理是什么体验？

# 1、产品经理的职责有哪些？到底该做什么？

简单来说就是设计产品的，并且实现它。

注意，这里说的设计不是画图，而是功能规划。

产品经理工作不包括运营，运营请出门左转。

到底该做什么？太多了。需求分析、项目管理、产品设计、数据分析、测试，等等。

这些基本上是主要功能。此外还有很多杂七杂八的.

跟你们说一大堆概念只会让你们越听越懵。记住核心是设计和沟通就行了。

# 2、产品经理的一天是怎样的？

大部分时候不忙，甚至很闲，总体来说可以用轻松来形容--直到项目开始了。

# 3、产品经理为什么会存在？

产品经理在中国的出现大概是始自2004年左右。

之前的那几年是互联网的萌芽阶段，是没有产品经理的。

因为那时候的产品形态很单一，功能也不复杂。不需要专门有人去规划设计。

后来为什么出现了呢？

因为web2.0时代到来了。

# 29、小白如何一步一步、条理清晰的学习PM相关知识？入职产品助理

这个问题有两个部分组成，其中第二个是错误的问题。 1、小白如何一步一步、条理清晰的学习PM相关知识？ 答：还是那句话，先确保自己的学习路径是没错的，再说如何一步步的学习。 然后可以大致参照以下顺序： 1.1、从基本概念开始，树立正确的基本产品认知 1.2、了解竞品，做竞品分析。掌握基本的需求分析方法 1.3、掌握工具和设计方法，设计规范。 1.4、大量项目实践练习。注意，项目实践不是临摹。临摹只能提高工具熟练度，对经验获取毫无帮助。 问题二：入职产品助理 这是个伪命题。产品助理就不应该在求职考虑的范围之内。

# 36、分析用户流失的原因，应该从哪些原因入手分析？

作为一个产品经理，正确的分析思路应该是这样的：

按照以下顺序，排查原因： 1、是不是技术的原因，不稳定，速度慢，用户使用不顺畅，所以流失。 2、是不是运营的原因，东西卖的太贵，活动搞的太差。用户不喜欢，所以流失。 3、是不是内容的原因，编辑写的稿质量太低，发文章频率太低。用户不爱看，所以流失。 4、是不是测试的原因，有些bug测试没测出来，但是用户发现了，所以流失。 5、是不是客服的原因，对客户的服务态度太差，用户不满意，所以流失。 6、是不是服务的原因，例如物流太慢，用户不满意，素以流失。 7、是不是以上方面都有问题，用户不满意，所以流失。 8、如果以上方面都没找到原因，那就再回到第一条开始，再找一遍。 9、无限重复以上循环。 10、总之不是产品的原因。
