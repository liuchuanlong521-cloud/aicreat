核心考点

前言

如果你在前面几章已经系统学习了AI产品的方法论、需求分析、模型选型、交互设计，那么从这一章开始，我们将正式进入AI产品经理的"商业思维"训练场。

很多AI PM有一个共同的困惑："我负责的产品技术很牛，用户体验也不错，但为什么就是赚不到钱？"或者"为什么OpenAI烧了几百亿美元还在亏损，而Midjourney只有十几个人却年入几亿美金？"

答案很简单：AI产品和AI商业是两个维度的事情。懂产品的人不一定懂商业，但不懂商业的AI PM，天花板一定很低。本章我将从一个AI产品经理的视角，带你重新理解AI商业的本质逻辑、赚钱模式、竞争壁垒和关键决策。学完这一章，你会对"AI到底怎么赚钱"有一个系统性的认知框架。

# 一、AI商业与传统商业的根本差异

在谈AI商业之前，我们必须先回答一个问题：AI商业和传统互联网商业，到底有什么不同？

核心考点

核心观点

传统商业的本质是"连接效率"，AI商业的本质是"智力替代"。这个根本差异导致了两者在成本结构、增长逻辑和竞争壁垒上的全面分化。

# 1.1 边际成本：从"趋近于零"到"真的趋近于零"

传统互联网产品的边际成本已经很低了。多一个用户看抖音，字节跳动的服务器成本增加几分钱；多一个人下载微信，腾讯的成本几乎为零。这是互联网商业的底层逻辑——规模效应建立在边际成本递减之上。

但AI产品把这个逻辑推向了极致：

维度传统互联网产品AI产品（以ChatGPT为例）
服务第1个用户服务器成本 + 研发摊销模型训练成本（数千万~数亿美元）+ 推理算力
服务第100万个用户边际成本≈0边际成本≈0（但每个用户有持续Token消耗）
服务第1亿个用户边际成本≈0边际成本依然很低，但算力成本线性增长
成本大头人力、服务器、带宽训练算力、推理算力、数据获取
可变成本占比低极高

名师旁白

注意

AI产品的边际成本不是绝对的零。每一次用户提问，都需要消耗真实的GPU算力和电力。这意味着AI产品永远无法像传统SaaS那样实现"纯软件式"的边际成本递减。理解这一点，对你后续做定价策略至关重要。

# 1.2 规模效应：从"用户规模"到"数据规模"

传统互联网的规模效应是网络效应：用户越多，产品越有价值（微信、淘宝、抖音都是典型）。

AI商业的规模效应是数据飞轮：

用户越多 → 产生更多数据 → 数据用于训练/微调 → 模型效果更好 → 产品体验更好 → 用户更多
1

但这个飞轮有个前提：数据必须回流到模型训练闭环中。

关键陷阱

关键陷阱

很多AI PM误以为"用户多=数据多=模型好"，这是错的。如果你的产品架构设计中没有把用户交互数据回流到模型迭代的管道，那么用户增长和模型进步之间就是断开的。你只是在做传统互联网产品，不是在玩AI商业。

# 1.3 网络效应：从"人与人的连接"到"人与AI的共生"

传统网络效应的公式是 $V = n^2$（梅特卡夫定律），价值与用户数的平方成正比。

AI商业中，网络效应发生了质变：

  • 单边网络效应：用户使用越多，AI越懂你（个性化记忆、上下文理解）
  • 双边网络效应：用户提问数据帮助模型改进，模型改进吸引更多用户
  • 生态网络效应：开发者基于你的模型构建应用，应用丰富吸引更多终端用户
网络效应类型代表产品机制说明
单边（个性化）ChatGPT Plus用户的对话历史、自定义指令持续优化个人体验
双边（数据飞轮）Midjourney用户的Prompt和筛选行为直接训练下一代模型
生态（平台型）OpenAI GPTs Store开发者生态吸引用户，用户规模吸引开发者

# 1.4 数据飞轮：AI商业的"永动机"

数据飞轮（Data Flywheel）是AI商业最核心的概念，没有之一。

核心考点

给AI PM的实操建议

在设计产品时，一定要问自己三个问题：

  1. 用户和我的产品交互，产生了什么数据？
  2. 这些数据能回到模型训练流程中吗？
  3. 模型变好后，用户体验的提升能被用户感知到吗？

如果三个答案都是Yes，恭喜你，你在构建真正的数据飞轮。

# 二、AI商业的核心逻辑

理解了AI商业与传统商业的差异后，我们来看AI商业的三个核心逻辑。这三句话建议你背下来：

模型即服务（MaaS）、智力商品化、算力即权力。

# 2.1 模型即服务（Model as a Service, MaaS）

云计算时代，我们有IaaS（基础设施即服务）、PaaS（平台即服务）、SaaS（软件即服务）。AI时代，最核心的新范式是MaaS。

什么是MaaS？就是把AI模型的能力封装成可调用的服务，按用量计费。

// 传统SaaS的调用方式：买一个账号，按月付费
const saasSubscription = {
  plan: 'pro',
  price: 29.99, // $/月
  features: ['featureA', 'featureB']
};

// MaaS的调用方式：按Token计费，用多少付多少
const maasBilling = {
  inputTokens: 1000,
  outputTokens: 500,
  pricePer1KInput: 0.0015,
  pricePer1KOutput: 0.006,
  totalCost: (1000/1000)*0.0015 + (500/1000)*0.006
};

注意

MaaS的低毛利率是很多AI创业公司活不下去的根本原因。如果你的产品完全基于调用第三方API构建，而没有任何自有数据或模型壁垒，那么你的毛利天花板就是API价格和你的售价之间的差额。这个差额，通常薄得可怜。

# 2.2 智力商品化（Commoditization of Intelligence）

这是AI商业最深刻的变革。传统商业中，"智力"是一种稀缺资源。一个顶级咨询顾问年薪百万，一个资深律师按小时收费，一个优秀医生的诊断能力无法规模化复制。

AI正在做的事情，是把智力变成一种可以批量生产、按需调用、按量计费的商品。

智力类型传统供给方式AI替代方案成本变化
基础文案写作雇佣文案专员GPT-4o/Claude降99%
代码编写雇佣初级程序员GitHub Copilot降80%
图像设计雇佣设计师Midjourney/SD降95%
客户服务雇佣客服团队AI客服机器人降90%
数据分析雇佣数据分析师AI数据助手降85%
法律咨询雇佣律师AI法律助手降90%

核心考点

给AI PM的洞察

智力商品化意味着两件事：

  1. 破坏性创新：所有基于"人力智力溢价"的商业模式都会被重构。
  2. 新机会：在智力被商品化后，"如何更好地使用智力"、"如何把智力嵌入业务流程"本身变成了新生意。AI PM的核心价值，正是设计"智力嵌入业务"的最佳方式。

算力即权力体现在三个层面：

  1. 训练权力：谁能买到/租到足够多的高端GPU，谁就能训练更大的模型
  2. 推理权力：谁的推理成本更低，谁就能在C端价格战中有更大空间
  3. 议价权力：云厂商（AWS/Azure/GCP）通过控制算力供给，正在向上游（模型层）和下游（应用层）同时施加影响力

# 三、AI商业的四种赚钱模式

如果你要创业或者负责一个AI产品的商业化，你必须清楚：AI行业只有四种赚钱模式，所有公司都逃不出这个框架。

# 3.1 卖算力：基础设施层的"卖水人"

这是最底层、最稳定、但也最"苦"的生意。

谁在卖算力？

  • 云厂商：AWS、Azure、Google Cloud、阿里云、腾讯云
  • GPU租赁商：CoreWeave、Lambda Labs、国内的燧原科技
  • 智算中心运营商：各地政府建设的AI算力中心

商业模式：

服务类型计费方式毛利率特点
训练算力租赁按GPU小时计费（$2-5/小时）40-60%需求波动大，大模型训练时一卡难求
推理算力租赁按请求/Token计费30-50%需求稳定，但价格战激烈
算力订阅包月/包年（预留实例）50-70%现金流稳定，客户粘性强
算力转售低价批量采购+加价零售15-30%门槛低，竞争激烈

给AI PM的启示：

  • 卖算力的生意本质上是"资源生意"，核心壁垒是资金（买GPU）和规模（建数据中心）
  • 对大多数AI PM来说，你不是算力提供商，而是算力消费者。理解算力成本结构，是为了更好地控制产品成本

# 3.2 卖模型：模型层的"卖芯片设计图"

谁在卖模型？

  • 闭源模型厂商：OpenAI、Anthropic、Google、百度、阿里
  • 开源模型+服务：Meta（Llama）、Mistral、智谱AI（ChatGLM）

商业模式：

模式说明代表案例毛利率
API按量计费按Token收费OpenAI API30-50%
模型订阅个人/企业按月订阅ChatGPT Plus $20/月60-80%
开源+云服务模型免费，云服务收费Llama + AWS托管20-40%
模型授权一次性授权费部分垂直模型厂商70%+

关键洞察：

  • 卖模型的生意，本质上是"卖智力"。模型越强，定价权越高
  • 但模型的技术壁垒正在快速被侵蚀（开源模型追近闭源模型），长期看模型层会走向" commoditization（商品化）"
  • 未来的模型层赢家，要么是技术绝对领先（OpenAI），要么是生态最开放（Meta/Llama），要么是成本最低（DeepSeek）

# 3.3 卖应用：应用层的"卖解决方案"

这是AI PM最应该关注的层，因为大多数AI PM都在应用层工作。

谁在卖应用？

  • C端AI工具：Midjourney、Character.AI、Perplexity
  • B端AI SaaS：Cursor、Notion AI、各类AI客服/知识库/营销工具
  • 行业解决方案：AI医疗、AI金融、AI教育、AI制造

应用层的商业模式最多样化：

模式说明代表产品适合场景
订阅制按月/年付费ChatGPT Plus、Cursor个人生产力工具
按量付费按调用量/Token付费各类API集成应用B端工具、开发者工具
免费增值基础免费，高级付费ChatGPT免费版、文心一言获客导向、流量型产品
广告模式免费使用，广告变现Perplexity（部分）、AI搜索信息型产品、高频使用
交易抽佣从交易中抽取佣金AI电商导购、AI招聘交易撮合型产品
企业定制私有化部署+定制开发金融/政务/医疗AI方案高客单价、强合规需求

给AI PM的启示：

  • 应用层的核心竞争力不是"用了什么模型"，而是**"解决了什么问题"**
  • 同样的GPT-4o，有人做成ChatGPT（月活数亿），有人做成某个小众工具（月活几千）。差距在于产品设计和场景选择
  • 应用层的毛利率通常高于模型层（因为可以叠加产品溢价），但护城河也相对较浅

# 3.4 卖数据：数据层的"卖原材料"

谁在卖数据？

  • 数据标注公司：Scale AI、Appen、数据堂、海天瑞声
  • 数据集提供商：Hugging Face Datasets、各类行业数据集公司
  • 数据清洗/合成服务商：利用AI生成合成数据、清洗脏数据

商业模式：

服务类型计费方式毛利率特点
数据标注按标注量计费（$0.01-0.5/条）30-50%劳动密集型，但质量是核心壁垒
数据集销售一次性购买或订阅60-80%高质量稀缺数据集溢价极高
合成数据生成按生成量计费50-70%解决隐私和稀缺数据问题
数据清洗按处理量计费40-60%技术含量中等，但需求稳定

给AI PM的启示：

  • 数据是AI的"石油"，但原始数据（crude oil）不值钱，精炼后的数据（gasoline）才值钱
  • 如果你所在的公司有独特的数据资产（如电商交易数据、医疗影像数据、金融风控数据），这是比模型更强的护城河

# 四、AI商业的竞争壁垒

# 4.1 四种壁垒的对比

壁垒类型说明强度代表案例
模型能力壁垒拥有更强的大模型⭐⭐⭐OpenAI（GPT-4o）、Anthropic（Claude）
数据资产壁垒拥有稀缺、高质量、独家的数据⭐⭐⭐⭐⭐TikTok（推荐数据）、Google（搜索数据）
用户粘性壁垒用户迁移成本高、使用习惯深⭐⭐⭐⭐ChatGPT（对话历史）、Midjourney（风格库）
生态闭环壁垒开发者/上下游围绕你构建生态⭐⭐⭐⭐⭐OpenAI（GPTs Store）、Meta（Llama生态）

# 4.2 壁垒的动态变化

模型能力壁垒正在弱化：

  • 2023年：GPT-4一骑绝尘，其他模型差距明显
  • 2024年：Claude 3、Gemini 1.5、Kimi追近GPT-4
  • 2025年：开源模型（Llama 3、Qwen 2.5）接近闭源模型水平
  • 趋势：模型能力壁垒的半衰期约12-18个月

数据资产壁垒在强化：

  • 通用数据（网页、书籍）已经耗尽，高质量数据越来越稀缺
  • 垂直领域数据（医疗、金融、法律）由于隐私和合规限制，更难获取
  • 趋势：数据资产壁垒的半衰期约3-5年

生态闭环壁垒最持久：

  • 一旦开发者和用户在你的生态上构建了大量应用和工作流，迁移成本极高
  • 趋势：生态壁垒的半衰期约5-10年

给AI PM的决策框架：

你在构建产品时，问自己：
1. 我的模型能力是行业Top 3吗？如果不是，不要以模型为壁垒。
2. 我有独特的数据资产吗？如果有，把数据飞轮设计进产品。
3. 我的用户会积累什么"个人资产"？（对话历史、自定义设置、创作作品）
4. 有开发者在基于我的产品构建应用吗？如果没有，考虑开放API或插件生态。

# 五、AI商业的阶段性特征

AI商业的发展，可以类比为一个人的成长阶段：

# 5.1 技术驱动期（2022-2024）

特征：

  • 谁有更强的模型，谁就能吸引用户
  • 产品功能简单，核心卖点是"AI能做什么神奇的事"
  • 用户愿意为"新鲜感"付费

典型案例：

  • ChatGPT上线5天用户破百万，核心原因是"第一个能聊天的AI"
  • Midjourney早期用户增长靠"AI能画出这么好看的图"

PM的核心任务：

  • 快速验证技术可行性
  • 找到AI能力与用户需求的匹配点
  • 积累早期用户和数据

# 5.2 产品驱动期（2024-2026）

特征：

  • 模型能力差距缩小，产品体验成为差异化关键
  • 用户不再为"新鲜感"付费，而是为"解决实际问题"付费
  • 商业化成为核心议题

典型案例：

  • Cursor vs GitHub Copilot：两者模型能力相近，但Cursor靠产品体验（Composer、Agent模式）赢得开发者
  • 各类AI工具从"免费试用"转向"付费订阅"

PM的核心任务：

  • 深耕用户场景，打磨产品体验
  • 建立数据飞轮和用户粘性
  • 跑通商业模式，实现正向现金流

# 5.3 运营驱动期（2027-未来）

特征：

  • AI能力成为基础设施，就像今天的云计算一样
  • 竞争焦点从"有没有AI"转向"AI用得有多好"
  • 行业整合，巨头通吃，细分垂直领域出现小而美的玩家

PM的核心任务：

  • 精细化运营，提升用户LTV
  • 构建生态，形成网络效应
  • 通过并购或战略合作巩固市场地位

# 六、AI PM必须理解的商业指标

# 6.1 单位经济模型（Unit Economics）

单位经济模型是AI产品商业化的"体检报告"。

单次请求成本 = 输入Token成本 + 输出Token成本 + 系统开销

单用户月均成本 = 月均请求次数 × 单次请求成本

单用户月均收入（ARPU）= 订阅费/月 或 按量付费收入

单用户月毛利 = ARPU - 单用户月均成本

LTV（用户生命周期价值）= 单用户月毛利 × 用户平均留存月数

CAC（用户获取成本）= 营销总费用 / 新增用户数

# 6.2 Token成本占比

Token成本占收入的比例，是衡量AI产品健康度的关键指标。

健康度Token成本占收入比说明
🟢 健康< 20%有充足的毛利空间覆盖研发、营销、管理费用
🟡 警戒20-40%需要优化模型选型或提升定价
🔴 危险> 40%毛利极低，规模化后可能亏损

优化方向：

  • 模型分层：简单任务用小模型，复杂任务用大模型
  • Prompt缓存：减少重复的系统Prompt开销
  • 用户分层：免费用户用轻量模型，付费用户用旗舰模型

# 6.3 模型迭代ROI

每次模型升级（如从GPT-3.5升级到GPT-4），都需要评估ROI：

模型迭代ROI = (升级后收入增长 + 成本节约) / 升级投入成本

升级投入成本 = 模型研发/采购成本 + 迁移开发成本 + 测试验证成本

# 七、AI商业中的关键决策

# 7.1 自研模型 vs 调用API

维度自研/微调模型调用第三方API
前期投入极高（数百万~数千万美元）极低（几千美元即可启动）
技术壁垒高低
成本可控性高（长期边际成本低）低（受厂商涨价影响）
灵活性高（可深度定制）中（受限于API能力）
数据隐私完全可控需信任第三方
适用情况日均调用>100万次、数据敏感、有技术团队初创阶段、快速验证、非核心能力

决策框架：

如果你的产品日均API调用量 < 10万次 → 直接调用第三方API
如果你的产品日均API调用量 10-100万次 → 混合策略（核心场景自研，边缘场景调用API）
如果你的产品日均API调用量 > 100万次 → 考虑自研或深度定制

阶段时间核心动作商业模式
非营利研究2015-2019发布GPT-1/GPT-2靠捐赠和微软投资养活

PM启示：

  • OpenAI的商业化路径是"由B到C再到B"：先靠API服务企业开发者，再用ChatGPT引爆C端，最后用C端品牌反哺B端企业销售
  • 核心壁垒不是技术（技术会被追近），而是"品牌认知"和"生态锁定"

# 8.2 Midjourney：小而美的极致打法

商业数据：

  • 团队规模：约40人
  • 年收入：约2-3亿美元（2024年）
  • 用户规模：约2000万注册用户
  • 融资情况：零外部融资，完全靠收入自我造血

成功要素：

要素具体做法
极致聚焦只做一件事：文生图。不扩赛道，不做视频，不做聊天
社区驱动Discord社区是核心战场，用户生成的作品本身就是营销内容
数据飞轮用户的Prompt和筛选行为，直接用于训练下一代模型
轻量运营没有销售团队，没有企业定制，纯线上自助订阅
品牌溢价在设计师群体中建立了"Midjourney = 高品质AI图"的品牌认知

PM启示：

  • 在巨头环伺的AI赛道，"小而美"依然有机会，关键是极致聚焦 + 社区运营 + 数据飞轮
  • 不需要做大而全，做一个细分赛道的"第一名"，同样可以获得极高的商业回报

# 8.3 DeepSeek：性价比颠覆者

商业策略：

  • 开源+低价API：用极低的API价格（同类产品的1/10~1/20）快速获取开发者
  • 技术实力背书：模型效果接近GPT-4o，但训练和推理成本极低
  • 纯技术驱动：几乎不做营销，靠开发者口碑传播

PM启示：

  • 在模型层走向 commoditization 的趋势下，"成本领先"是一种有效的竞争策略
  • 但成本领先需要真正的技术创新支撑，单纯的"价格战"不可持续

# 九、写在最后

AI商业是一个快速演化、充满不确定性的领域。作为AI产品经理，你不需要成为商业战略专家，但必须理解以下三个核心认知：

核心考点

三个核心认知

  1. AI产品的成本结构与传统软件完全不同。每一次用户交互都有真实的算力成本，定价和成本控制是产品设计的一部分。

  2. 数据飞轮是AI产品最核心的护城河。没有数据回流机制的产品，只是套着AI外壳的传统软件。

  3. 模型能力正在快速 commoditization。不要把模型当作壁垒，要把"场景理解、用户粘性、数据资产、生态闭环"当作壁垒。

AI商业的终局，不是某一家公司通吃，而是一个分层、分工、协作的生态系统：有人卖算力，有人卖模型，有人卖应用，有人卖数据。作为AI PM，你的角色是在这个生态中找到属于你的位置，设计出有商业价值、有用户价值、有社会价值的产品。
