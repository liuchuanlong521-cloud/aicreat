# 微信"小微"灰度测试，超级App如何做AI入口？

6 月，微信宣布开放 AI 生态，灰度测试智能体"小微"。用户可以在微信内通过自然语言，让 AI 调用小程序完成订餐、比价、订酒店、打车等操作。首批内测应用包括美团、携程、同程、滴滴、猫眼等。

几乎同时，支付宝推出 AI 版，智能体定名"阿宝"。两大超级 App 同时把 Agent 入口摆到了台面上。

# 一、为什么超级 App 是 AI 入口的最佳土壤？

微信做"小微"有一个得天独厚的优势：小程序生态。

根据阿拉丁研究院数据，截至 2026 年一季度，微信小程序数量达到 840 万，占全网小程序的 70%。QuestMobile 数据则显示，2026 年 3 月微信小程序月活用户规模已达 9.73 亿。

这意味着：

  • 用户不需要下载新 App
  • 服务不需要重建交易闭环
  • AI 可以直接调用已经成熟的小程序能力

对微信来说，"小微"不是从零开始做一个 AI 助手，而是给已有的庞大生态加一个自然语言入口。

# 二、"小微"到底在做什么？

从现有信息看，"小微"的核心能力是：

  • 理解用户自然语言意图："帮我找一家附近的火锅店，人均 100 以下"
  • 调用小程序完成任务：打开美团、大众点评等小程序选店、下单
  • 打通支付闭环：通过微信支付完成扣款

更具体的一个案例是：6 月 17 日，微信支付接入腾讯桌面智能体 WorkBuddy，用户可以通过微信下指令，WorkBuddy 选品购买，再用微信支付专为 AI 开通的扣款渠道付钱。

这说明腾讯内部的 Agent 布局正在打通：微信负责入口和支付，WorkBuddy 负责桌面执行，小程序负责服务供给。

# 三、支付宝"阿宝"的应对：另一种入口思路

支付宝推出"阿宝"，逻辑和"小微"类似：也是通过 Agent 调用支付宝小程序完成服务。

但两者的禀赋不同：

维度微信"小微"支付宝"阿宝"
用户关系社交关系链交易和金融关系链
小程序生态840 万小程序，生活服务和社交为主小程序数量仅次于微信，金融和本地生活强
支付能力微信支付支付宝支付
使用场景聊天场景中自然触发消费、理财、办事场景中触发
核心优势高频社交 + 海量小程序交易闭环 + 信用体系

这场竞争的本质不是"谁家的 AI 更聪明"，而是谁的生态更适合 Agent 调用服务。

# 四、平台博弈：谁掌握调用权？

Agent 入口之争背后，还有一个更深层的问题：谁来决定 AI 能调用哪些服务？

  • 对微信/支付宝来说，它们是平台，掌握小程序的调用规则和流量分配
  • 对美团、携程、滴滴等应用来说，它们是被调用的服务方，需要权衡"被 AI 调用"带来的流量和失去的用户关系
  • 对用户来说，Agent 让服务获取更便利，但也意味着自己更依赖超级 App

未来可能会出现一种新的权力结构：AI 助手成为流量的分配者，小程序成为能力的提供者，超级 App 成为规则的制定者。

# 五、对产品经理的启示

  1. Agent 入口的竞争，本质上是生态竞争。 模型能力会快速拉平，但小程序数量、支付闭环、用户关系链这些生态壁垒很难复制。

  2. 对于服务类产品，要重新思考"被 AI 调用"的策略。 你的产品是希望用户打开 App 使用，还是愿意被 Agent 作为能力层调用？两种方式对应的商业模式完全不同。

  3. 自然语言交互会改变产品形态。 用户可能不再需要翻找菜单、填写表单，而是直接说需求。产品设计的重点会从"界面设计"转向"意图理解和结果交付"。

  4. 平台规则会决定 Agent 的天花板。 微信、支付宝对 Agent 能调用什么、不能调用什么、怎么抽成、怎么分配流量，都会深刻影响 Agent 产品的形态。

  5. Agent 时代，用户关系可能被平台截断。 如果用户只通过"小微"订酒店，携程/美团的品牌价值和用户粘性会被稀释。服务方需要思考如何在 Agent 生态中保持存在感。

# 最后

微信"小微"和支付宝"阿宝"的上线，标志着中国互联网的竞争从"App 之争"进入了"Agent 入口之争"。

未来的用户可能不再说"打开美团点个外卖"，而是说"帮我点份外卖"。至于背后是哪个 App 提供的服务，用户可能并不关心。

这对产品经理的影响是深远的：

  • 如果你做的是超级 App，要想的是如何让 AI 成为生态的统一入口
  • 如果你做的是垂直服务，要想的是如何在 Agent 生态中保持被调用的价值
  • 如果你做的是 AI 产品，要想的是如何连接尽可能多的服务闭环

Agent 不会消灭 App，但它会重新定义 App 的入口形态和商业逻辑。

思考题：如果你负责一款垂直服务 App（比如酒店预订），你会选择自己做 Agent，还是接入微信/支付宝的 Agent 生态？各自的利弊是什么？
